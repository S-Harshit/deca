# Deca tests

Two kinds, both run by `run.mjs`:

- **Unit tests** (`unit/`): plain Node, no browser. They load the app's own source (signed events, the room log, message parsing, export/import, the no-server code logic, the launcher...). Fast.
- **Browser tests** (`browser/`): Playwright drives real Chromium against the running app: several people in one room, calls with fake cameras, files, themes, phones, the no-server mode, and so on.

## Run them

```
cd tests
npm install
npx playwright-core install chromium     # once; or set CHROME_PATH to a Chrome/Chromium you already have
node run.mjs                             # everything (about 20-30 minutes)
node run.mjs quick                       # a fast, representative subset
node run.mjs unit                        # unit tests only
node run.mjs scores room                 # any suite whose name contains one of the words
```

The runner starts the app itself on `http://localhost:8080` from `dema-client/dist` (it builds it first if missing), or reuses one that is already answering there. **Rebuild the client after changing it** (`cd dema-client && npm run build`), because the server serves the built files. Browser suites run one at a time on purpose: they share one server and its per-address limits.

A failing suite is retried once (`RETRIES=0` to turn that off) because a few are timing-sensitive; a retry that passes is reported as such.

## Notes

- The tests are written against `http://localhost:8080/`. `DECA_URL` points navigation at an app running elsewhere, but a few suites also check text that contains the address, so use port 8080 when you can.
- **Needs internet:** `music-*` play a real YouTube video. `static-build` builds `dist-static` first if missing (which downloads Freedoom's data file when it can).
- **Slow:** `code-mode-slow` waits on purpose (30 s per code, to prove a slow human is not reported as a failure). It takes a couple of minutes.
- Browser tests assert on behaviour and measure layout, not just screenshots.
- Unit tests use `.build/` (generated by `lib/prep-unit.mjs`, git-ignored): Node cannot import the app's extensionless paths, so the needed files are copied with `.ts` added to their imports.

## Layout

```
run.mjs          the runner
lib/browser.*    how tests start a browser (CHROME_PATH, DECA_URL)
lib/prep-unit.mjs  copies app source for the unit tests
unit/            unit tests
browser/         browser tests (one topic per file)
```
